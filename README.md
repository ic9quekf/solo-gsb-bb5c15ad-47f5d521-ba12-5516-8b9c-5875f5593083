# 离心机转子配平规划器 (Centrifuge Rotor Balance Planner)

在给定**转子槽位角度、试管质量、禁用槽位与锁定试管**约束下，搜索近似最优的对称布局，
计算**一阶不平衡量（离心合力/合力矩）与二阶不平衡量**，对锁定试管执行**增量重排**，
逐步**解释每个配对依据**，支持**方案回放**与**JSON 导出**；并支持**互斥试管隔离**
（至多 12 对试管不得落在按角度环形排序后相邻的物理槽位，禁用槽仍占相邻关系；含互斥对时
限 7 管 / 10 启用槽，对全部合法摆放做**精确完全枚举**，锁定管互斥冲突或无合法摆放时
明确返回不可行且不保存方案）；并对**已保存方案**提供九项
**只读**分析：一是**称重误差校核**——在各管称重误差可独立正负变化的区间内，精确求
出最不利一阶不平衡量及一组对应的实际质量；二是**实测振动校准**——输入同一转速下试重前、
装入试重后的振动幅值与相位、试重质量及其空闲启用槽，按影响系数法在各空闲槽位逐一预测单枚
配重后的残余振动并给出推荐（试重视为已取下，均不覆盖原方案）；三是**批次换装顺序**——
选取 2~10 条已保存方案，以空转子为起点，用 Held-Karp 子集动态规划**精确**求卸下/装入
总操作数最少的执行次序（同成本按方案 ID 序列升序裁决），逐批给出卸装清单与单次/累计
操作数（不改动原方案）；四是**逐管安全装载**——选定一条已保存方案，从空转子开始每步
只装入一支试管（最终槽位不变），用子集动态规划（2ⁿ，n≤16）**精确**求全过程峰值 |U₁|
最小的装载次序（并列最优按试管编号序列升序裁决），可填装载阶段限值并逐步给出装入管号、
槽位、当步 |U₁|、累计峰值与超限步骤（超过 16 支明确拒绝，不覆盖原方案）；五是**失效
槽位应急迁移**——选定一条已保存方案，填写新失效槽位、一阶不平衡量限值与最多可移动管数，
基于原质量、槽角与半径生成只读迁移建议；锁定试管不得移动、失效槽位不得占用，在移动管数
上限内按移动管数分层**精确**寻找满足限值的摆放（先使移动管数最少，再使最终 |U₁| 最小，
并列时按管号升序的目标槽位序列裁决），仅接受至多 10 支管、16 个启用槽位、移动上限 0~3
的方案，无可行摆放时明确说明（不覆盖原方案）；六是**现场装管复核**——选定一条已保存
方案，按启用槽录入实际有管槽位及天平实测质量（精度 0.01 g，至多 12 份）与统一允许偏差，
后端只在质量差不超过偏差的边上求方案试管与实测读数的**一对一匹配**，用子集动态规划
**精确**求总绝对质量差最小的最优匹配，并对每个实测槽汇总**所有最优匹配**可能对应的
试管：唯一时按原方案槽位标为**正确 / 错槽**，多解时标为**身份不确定**（不任取一解
断言错放）；读数数量与方案管数不等或不存在完整匹配时明确说明原因（不覆盖原方案）；
七是**复称规划**——选定一条已保存方案，录入各管当前质量误差上界、复称后的统一误差
上界、一阶不平衡量限值与最多复称次数（0~3），复称某管只把该管误差上界降至**两者较小
值**（标称质量与落槽不变），后端按复称管数分层**精确枚举**复称组合，每个组合调用现有
最不利 |U₁| 计算（二维 zonotope 顶点枚举）：先求能达标的**最少复称管数**，再在该管数
内取**最不利值最低**的组合（并列按管号序列升序裁决）；次数内均无法达标时给出次数内
最不利值最低的组合及超限量，**不误报达标**（不覆盖原方案）；
八是**库存配重补偿**——选定一条已保存方案，读取方案中的试管质量、槽角、半径与占用
状态，录入至多 6 种标准配重的质量与库存件数、一阶不平衡量限值与最多放置枚数（0~3），
后端仅处理至多 16 个空闲启用槽位，按放置枚数分层**精确枚举**槽位与配重质量的联合
组合（配重只放空闲启用槽、单槽至多一枚、每种用量不超库存，同质量种类合并库存）：
先求能达标的**最少放置枚数**，再在该枚数内取**残余 |U₁| 最低**的组合（并列按槽号
及对应质量序列升序裁决）；限额内无法达标时给出残余最低的组合及超限量，**不误报达标**
（不覆盖原方案）；九是**备品试管替换**——选定一条已保存方案中的 1~4 支待换管，录入
1~12 支编号唯一、质量为正且不与原方案管号冲突的备品及一阶不平衡量限值，备品装入待换管
原槽（保留原槽位）、备品不重复使用（一对一映射）、未换管保持不动，后端按原槽角度与半径
精确枚举全部 P(s,r) 个映射并重算最终 |U₁|：在达标映射中先取**总质量差最小**者，再按
**残余 |U₁|** 及**待换管号顺序对应的备品编号**裁决；无达标映射时返回残余最低的映射、
超限量与**不达标**结论（不覆盖原方案）。

技术栈：Python 3.11 · FastAPI · SQLite · 原生 HTML/CSS/JS（无前端构建）· Docker Compose。

## 一键启动

```bash
docker compose up --build
```

启动后浏览器访问：

- 应用界面：<http://localhost:8000>
- 健康检查：<http://localhost:8000/api/health>
- OpenAPI 文档：<http://localhost:8000/docs>

服务监听容器内 **8000** 端口，`docker-compose.yml` 默认映射到宿主机 **8000**
端口（`"8000:8000"`，可按需修改宿主端口）。

停止：`docker compose down`（数据保留在宿主机 `./data/balancer.db`）。

## 端口与配置

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 服务端口 | `8000` | 在 `docker-compose.yml` 的 `ports` 修改宿主端口，如 `"18000:8000"` |
| 数据库文件 | `/app/data/balancer.db` | 环境变量 `BALANCER_DB`，通过卷 `./data:/app/data` 持久化 |
| 槽位数 | 12 | 界面/API 可改（2–128），支持任意（含非均匀）角度 |
| 转子半径 R | 100 mm | 用于把不平衡量换算为离心力/力矩 |
| 转速 | 4000 rpm | 仅影响力学量（F、M），不影响布局优化 |
| 一阶权重 w₁ | 1.0 | 一阶不平衡量（主导离心合力）权重 |
| 二阶权重 w₂ | 1e-6 | 二阶（2 倍频）权重，默认仅在一阶几乎持平时作裁决 |
| 移动罚权 | 0.0 | 增量重排时每支被移动试管的罚分；调大可减少扰动 |
| 随机起点数 | 10 | 多起点搜索的起点数 |
| 退火链长度 | 2500 | 每个起点模拟退火步数（越大越慢、通常越优） |

> 物理量定义见 `GET /api/config`。

## 本地（不用 Docker）开发运行

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

核心求解算法 `app/balancer.py` 仅依赖标准库，可单独在 Python 中调用/测试：

```python
from app.balancer import run_plan
result = run_plan({
    "slots": [{"index": i, "angle": i*30, "enabled": True} for i in range(12)],
    "tubes": [{"id": 1, "mass": 50}, {"id": 2, "mass": 50},
              {"id": 3, "mass": 51}, {"id": 4, "mass": 49}],
    "radius_mm": 100, "rpm": 4000,
})
print(result["metrics"])
```

## 使用流程

1. **转子参数**：设置槽位数与半径/转速，点“按槽位数生成均布角度”，也可逐槽改角度；
   在左侧表格或转子图上切换槽位**启用/禁用**。
2. **试管清单**：录入编号与质量（g）；需要固定的试管勾选“锁定”并选择固定槽位。
3. **互斥试管隔离**（可选）：在“互斥试管隔离”面板用下拉框成对选择试管编号，至多
   12 对。每对试管不得落在**按角度环形排序后相邻的物理槽位**——注意相邻关系按全部
   物理槽（含禁用槽）建立，两个启用槽之间隔着禁用槽时**不算**相邻。含互斥对的请求
   限 **至多 7 支试管、10 个启用槽**；提交后后端改用精确完全枚举，而不是启发式搜索。
4. **计算配平方案**：无互斥对时在质量与角度约束下做多起点构造 + 模拟退火 + 爬山局部
   搜索，极小化 `w₁·|U₁|² + w₂·|U₂|²`；有互斥对时对全部合法摆放做精确完全枚举，
   精确取同一评分的最小值。
5. 查看右侧**合力矩、二阶不平衡量、评级**，以及转子图上的合力向量（蓝=U₁，绿=U₂）；
   有互斥对时转子图额外绘制灰色物理相邻环（含禁用槽）与红色互斥对连线。
6. **配对依据**标签页解释每一对对径/近对径试管的质量差、夹角与对消比例；
   无搭档的试管说明其补偿方式。
7. **方案回放**：用滑块/播放键逐步回放构造与微调过程，每步显示当时的 U₁/U₂ 与文字理由。
8. **增量重排**：先算出方案；增删试管或新增锁定后勾选“基于当前结果做增量重排”再计算。
   系统沿用上一方案中仍有效的摆放，仅重放受影响的试管，并标注“已移动”。
9. **导出 JSON / 历史方案**：保存到 SQLite，可再次载入、导出或删除。
10. **方案比较**：在“历史方案”中勾选两条已保存方案，点“比较选中的两条方案”，
   即可按试管编号合并摆放明细（新增 / 移除 / 换槽 / 未变），并并列查看两方案的
   一阶、二阶不平衡量及差值（B − A）。若两方案的转子几何或求解输入（转速、权重、
   试管清单等）不同，比较视图会显著提示参数差异——此时指标差值**不是同条件优化对比**，
   不能仅凭差值评判优劣。
11. **称重误差校核**：在历史方案中点“误差校核”，或载入已保存方案后点右侧
    “称重误差校核”。落槽与角度固定取自该方案（只读），逐管填写非负质量误差上界
    e<sub>k</sub>（0 ≤ e<sub>k</sub> ≤ 标称质量，实际质量按 m<sub>k</sub> ± e<sub>k</sub> 独立正负变化），
    可填一个一阶不平衡量限值。提交后并列显示标称 |U₁| 与**最不利** |U₁|、对应离心力、
    一组达到最不利值的实际质量（各管取 +e/−e），以及“合格 / 超限”判定。校核结果
    不保存、不覆盖原方案。
12. **实测振动校准**：在历史方案中点“振动校准”，或载入已保存方案后点右侧
    “实测振动校准”。槽位几何（角度/启用/占用）与半径只读取自方案；在**同一转速、
    同一测点与相位参考**下填写试重前（A₀、φ₀）与装入试重后（A₁、φ₁）的振动幅值与
    相位、试重质量及其所在**空闲启用**槽位，再给出若干可用配重质量（如 `1, 2, 5, 10`）。
    提交后展示影响系数 α、连续意义理想配重（仅对照），以及对每个空闲启用槽位 × 每枚
    可用质量的单枚配重预测（残余幅值、相位、相对原读数的改善量），**按残余幅值升序**，
    首项即推荐槽位与质量。试重**视为已取下**（预测以试重前读数 V₀ 为基线）；计算只读，
    结果不保存、不覆盖原方案。
13. **批次换装顺序**：在“历史方案”中勾选 2~10 条已保存方案，点“批次换装顺序”。
    系统以**空转子**为起点，精确规划使卸下/装入**总操作数最少**的执行次序（每卸下或
    装入一支试管各计 1 次；同成本按方案 ID 序列升序裁决），并逐批展示卸下清单、
    装入清单、保留不动的试管，以及本次与累计操作数。仅接受半径、槽位角度与启用状态
    完全相同的方案；同编号试管质量不一致会被拒绝（HTTP 400）。结果只读，不改动原方案。
14. **逐管安全装载**：在历史方案中点“安全装载”，或载入已保存方案后点右侧
    “逐管安全装载”。系统从**空转子**开始，每步只装入**一支**试管（各管最终槽位与
    该方案完全一致），按方案中的质量、槽角与半径计算各中间状态的 |U₁|，用子集动态
    规划（2ⁿ，n≤16）**精确**求**全过程峰值 |U₁| 最小**的装载次序；并列最优按试管
    编号序列升序裁决。可填写装载阶段限值，结果逐步显示装入管号、槽位、当步 |U₁|、
    累计峰值与超限步骤。超过 16 支试管明确拒绝（HTTP 400）。结果只读，不保存、
    不覆盖原方案。
15. **失效槽位应急迁移**：在历史方案中点“应急迁移”，或载入已保存方案后点右侧
    “失效槽位应急迁移”。填写**新失效槽位**（原本必须启用；最终摆放中任何试管都不得
    落在失效槽，原本禁用槽同样不可用）、**一阶不平衡量限值** |U₁| 与**最多可移动管数**
    （0~3）。锁定试管不得移动；系统在移动管数上限内按移动管数分层**精确枚举**满足
    限值的摆放——先使**移动管数最少**，再使**最终 |U₁| 最小**，并列时按**管号升序
    的目标槽位序列**裁决。结果给出逐管原槽/目标槽、移动清单、移动数与最终 |U₁|；
    无可行摆放时明确说明原因，并在可能时附移动上限内 |U₁| 最小的对照摆放。仅接受
    **至多 10 支管、16 个启用槽位、移动上限 0~3** 的方案（超出返回 400）。结果只读，
    不保存、不覆盖原方案。
16. **现场装管复核**：在历史方案中点“装管复核”，或载入已保存方案后点右侧
    “现场装管复核”。按**启用槽**逐槽录入现场实际有管槽位与天平实测质量（精度
    **0.01 g**，须为 0.01 的整数倍，至多 **12 份**；可点“按方案预填”快速带入方案
    槽位与标称质量再修改），并填写**统一允许偏差** e（g）。提交后服务端只在
    |标称 − 实测| ≤ e 的边上求方案试管与实测读数的**一对一匹配**，以**总绝对质量
    差最小**为准（子集动态规划精确求解），并对每个实测槽汇总**所有最优匹配**可能
    对应的试管：候选唯一时按原方案槽位标为**正确**或**错槽**，候选多解时标为
    **身份不确定**——不会任取一个最优匹配断言错放。读数数量与方案管数不等、或
    不存在完整匹配时明确说明原因（含最多可匹配对数与无兼容对象的清单）。复核
    结果只读，不保存、不覆盖原方案。
17. **复称规划**：在历史方案中点“复称规划”，或载入已保存方案后点右侧
    “复称规划”。逐管填写**当前**称重质量误差上界（0 ≤ e<sub>k</sub> ≤ 标称质量，
    未填按 0；可点“填入全部”批量统一），再填写**复称后的统一误差上界**、
    **一阶不平衡量限值**与**最多复称次数**（0~3）。复称某管只把该管误差上界
    降至**两者较小值**，标称质量与落槽不变。提交后服务端按复称管数分层
    **精确枚举**复称组合（至多 24 支已放置试管），每个组合调用现有最不利
    |U₁| 计算：先求能达标的**最少复称管数**，再在该管数内取**最不利值最低**
    的组合，并列按**管号序列升序**裁决。结果展示复称管号、复称前后最不利
    |U₁| 与合格/超限判定；次数内均无法达标时给出次数内最不利值最低的组合
    及超限量，**不误报达标**。结果只读，不保存、不覆盖原方案。
18. **库存配重补偿**：在历史方案中点“配重补偿”，或载入已保存方案后点右侧
    “库存配重补偿”。试管质量、槽角、半径与占用状态只读取自该方案（只读）。
    录入至多 **6 种**标准配重（**质量**与**库存件数**，同质量种类自动合并库存）、
    **一阶不平衡量限值** |U₁| 与**最多放置枚数**（0~3）。服务端仅处理至多
    **16 个空闲启用槽位**，按放置枚数分层**精确枚举**槽位与配重质量的联合
    组合：配重只放**空闲启用槽**、**单槽至多一枚**、每种用量**不超库存**；
    先求能达标的**最少放置枚数**，再在该枚数内取**残余 |U₁| 最低**的组合，
    并列按**槽号及对应质量序列**升序裁决。结果展示放置清单（槽位/角度/配重
    质量/质径积贡献）与补偿前后 |U₁|、合格/超限判定；限额内均无法达标时给出
    残余最低的组合及超限量，**不误报达标**。结果只读，不保存、不覆盖原方案。
19. **备品试管替换**：在历史方案中点“备品替换”，或载入已保存方案后点右侧
    “备品试管替换”。勾选 **1~4 支待换管**（均为方案中已放置试管），录入
    **1~12 支备品**（**编号唯一**、**质量为正**，且编号**不得与原方案管号冲突**），
    再填写**一阶不平衡量限值** |U₁|。备品装入待换管的**原槽位**（槽角与半径沿用
    原方案），**备品不重复使用**（一对一映射），未换管及其槽位保持不动。提交后
    服务端精确枚举全部 P(s,r) 个映射并重算最终 |U₁|：在达标映射中**先取总质量差
    最小**者，再按**残余 |U₁|** 及**待换管号（升序）顺序对应的备品编号序列**裁决；
    结果展示逐管替换映射（原管/原槽、备品编号与质量、质量差、替换前后质径积贡献）、
    保留不动的未换管以及替换前后 |U₁|/离心合力/总质量对比。备品少于待换管、编号
    冲突或重复、质量非正等均返回 400；**无达标映射**时给出**残余最低**的映射与
    **超限量**并明确判定不达标，**不误报达标**。结果只读，不保存、不覆盖原方案。

## 自定义槽位几何（编号与角度）

`POST /api/plan` 的 `slots` 数组描述转子的全部物理槽，每项形如
`{"index": 槽号, "angle": 角度(度), "enabled": 是否启用}`。槽号 `index` 是槽位的
**唯一身份标识**——锁定试管的固定槽、增量重排的旧槽、互斥相邻关系以及返回/保存的
摆放明细都按槽号索引，**与数组中的提交顺序无关**。

后端在求解前把槽位**按 `index` 规范化**为覆盖 `0 … slot_count-1` 的唯一序列：

- **允许乱序提交**：`slots` 可按任意顺序给出，后端按编号取对应角度求解；锁定管绝不会
  错按“列表第几个”的角度计算，保存的 `U₁/U₂`、摆放槽号、角度与指标都与该几何一致。
- **编号必须完整唯一**：编号须为整数，恰好覆盖 `0 … slot_count-1`，**重复、缺失或越界
  一律返回 400**（并在错误信息中指出问题编号），请求不落库。
- **默认角度按槽号生成**：某项省略 `angle` 或显式给 `null` 时，该槽取均布默认角度
  `360°·index/slot_count`；`slots` 整体省略或为空时，生成 `0 … slot_count-1` 的均布槽。
- **角度必须有限**：显式角度必须是有限数值，`NaN`/`Infinity`/`-Infinity` 返回 400。
  同角度的两个**启用**槽也会被拒绝（禁用槽不参与角度查重）。
- **物理相邻按实际角度**：互斥试管的环形相邻关系始终把全部物理槽（含禁用槽）按
  **实际角度**（同角按槽号）排序建立，与提交顺序、槽号差无关；非均匀角度直接按角度
  相邻。

规范化后的槽位（按槽号排序、默认角度已补全）会写入保存请求，因此历史方案、导出 JSON、
方案比较以及应急迁移/校准/配重等只读子流程使用的几何与求解时完全相同。乱序示例：

```json
"slots": [
  {"index": 3, "angle": 270, "enabled": true},
  {"index": 0, "angle":   0, "enabled": true},
  {"index": 2, "angle": 180, "enabled": true},
  {"index": 1, "angle":  90, "enabled": true}
]
```

与按 `0,1,2,3` 顺序提交完全等价；锁定在槽 `0` 的试管始终按 0° 计算。

## 数值边界（有限性与溢出校验）

`POST /api/plan` 中参与计算的所有数值——试管质量、半径、转速、优化权重 w₁/w₂ 与
移动罚权——都必须是**有限数值**（`NaN`/`Infinity`/`-Infinity` 一律返回 400，且
**不保存方案**；槽位角度的有限性校验见上节）。此外，即使每个输入本身有限，求解与
指标计算的中间量也可能溢出双精度浮点范围：总质量 M、质径积上界 M·R、目标函数上界
`(|w₁|+|w₂|)·M² + |移动罚权|·n`，以及 `ω → ω² → F = ω²·|U₁| → τ = F·R` 的力学
指标链。服务端在求解前按上述上界预先校验，并在结果形成时复核全部派生指标为有限值；
任一环节溢出即返回可读的 400 且不保存方案（直接调用 `app.balancer.run_plan` 时抛出
`ValueError`）。正常量级的数值求解行为与指标语义不变。

## 互斥试管隔离的计算方法（物理相邻环上的精确完全枚举）

每对互斥试管 `(tube_a, tube_b)` 要求：两支试管**不得落在按角度环形排序后相邻的物理
槽位**。后端把**全部物理槽（含禁用槽）**按角度（同角按索引）环形排序，槽 i 的相邻槽
是环上的前一个与后一个物理槽；因此禁用槽仍“占据”相邻关系——例如 12 槽转子中槽 1
被禁用后，槽 0 与槽 2 之间隔着槽 1，二者**不再相邻**；同理槽 10、11 禁用后，槽 9
与槽 0 也不相邻。非均匀角度按实际角度排序，不依赖槽号差。

为保证最优性，含互斥对的请求**不再使用启发式搜索**，而是在下列输入限制内做精确
完全枚举（回溯 + 互斥禁止槽传播 + 后续试管候选槽前向剪枝）：

- 至多 **12 对**互斥试管、成对编号不同、编号必须存在、无序重复对会被拒绝；
- 至多 **7 支试管**、**10 个启用槽**（叶子数上界 P(10,7)=604800，秒级完成）；
- 评分沿用质量/权重输入：`w₁·|U₁|² + w₂·|U₂|²`，增量重排时再加
  `move_weight·移动试管数`（沿用上一方案旧槽计 0 次移动）；
- 锁定试管先固定落槽；若互斥对的两支**均锁定且其固定槽物理相邻**，属结构性冲突，
  直接返回不可行；自由试管若在全部合法放置后仍无可行摆放，同样返回不可行。

DFS 按**管号升序**逐管、槽号升序枚举合法槽位，在叶子处比较评分；浮点容差（1e-9
相对容差，与应急迁移等精确模块一致）内平分时，取**管号升序的槽位序列**
`(slot(tube_id 最小), slot(tube_id 次小), …)` 字典序最小者。搜索结果返回精确评估的
合法摆放数。**不可行（HTTP 400）时不落库、不保存方案**；`mutex_pairs` 同时写入保存
请求，因此结果回放、导出 JSON、再次载入、方案比较都保留互斥约束（两方案互斥对不同
时，方案比较会提示求解输入差异）。

请求示例：

```bash
curl -X POST http://localhost:8000/api/plan \
  -H 'Content-Type: application/json' \
  -d '{
        "slot_count": 12,
        "slots": [
          {"index": 0, "angle":   0, "enabled": true},
          {"index": 1, "angle":  30, "enabled": true},
          {"index": 2, "angle":  60, "enabled": true},
          {"index": 3, "angle":  90, "enabled": true},
          {"index": 4, "angle": 120, "enabled": true},
          {"index": 5, "angle": 150, "enabled": true},
          {"index": 6, "angle": 180, "enabled": true},
          {"index": 7, "angle": 210, "enabled": true},
          {"index": 8, "angle": 240, "enabled": true},
          {"index": 9, "angle": 270, "enabled": true},
          {"index": 10, "angle": 300, "enabled": false},
          {"index": 11, "angle": 330, "enabled": false}
        ],
        "tubes": [
          {"id": 1, "mass": 50}, {"id": 2, "mass": 50}, {"id": 3, "mass": 49}
        ],
        "mutex_pairs": [{"tube_a": 1, "tube_b": 2}]
      }'
```

返回结果在 `result.exact_search` 中给出 `mutex_pairs / evaluated_arrangements /
kept_tube_ids / adjacent_slot_pairs`，摆放明细每项含 `mutex_with`（该管的互斥搭档
编号列表），回放步骤逐管展示精确落槽与避让说明。`mutex_pairs` 为空或缺省时，完全
沿用原有多起点 + 模拟退火 + 爬山启发式求解，行为不变。

## 实测振动校准的计算方法（单面影响系数法）

同一转速、同一测点/相位参考下，把振动读数表示为复数向量：

```
V₀ = A₀·e^(iφ₀)            试重前（原始）
V₁ = A₁·e^(iφ₁)            装入试重后
```

试重质量 mₜ 位于槽位 θₜ（必须存在、启用且空闲），质径积 Uₜ = mₜ·R·e^(iθₜ)（g·mm）。
线性假设下振动变化只由该试重引起：

```
影响系数  α = (V₁ − V₀) / Uₜ                       [振动单位/(g·mm)]
```

**试重视为已取下**，在任一空闲启用槽位 s 放置单枚配重 m 后的预测振动：

```
V(m, s) = V₀ + α·m·R·e^(iθ_s)
```

后端对方案中每个空闲启用槽位 × 每枚可用配重质量逐一计算 V(m, s)，按残余幅值
|V(m, s)| 升序排序，首项为推荐，并给出相对原读数的改善量 A₀ − |V| 与百分比
（A₀ = 0 时百分比不适用）。连续意义理想配重 U* = −V₀/α、m* = |U*|/R、
θ* = arg(U*) 仅作对照，不受槽位与离散质量限制（`app/calibration.py`，纯标准库）。

当试重前后振动向量几乎无变化（|V₁−V₀| ≤ 1e-9·max(|V₀|,|V₁|)，含两次读数都为零）时，
影响系数近零，说明试重未产生可辨识的响应，服务端**明确拒绝**给出配重推荐（HTTP 400），
而不是外推数值不稳定的结果；此时应检查试重是否过轻、两次读数是否同一转速/测点/相位参考。

校准接口的请求示例：

```bash
curl -X POST http://localhost:8000/api/plan/1/vibration-calibration \
  -H 'Content-Type: application/json' \
  -d '{"initial_amplitude":5.0,"initial_phase_deg":30.0,
       "trial_amplitude":6.2,"trial_phase_deg":52.0,
       "trial_mass_g":5.0,"trial_slot":9,
       "available_masses":[1,2,5,10]}'
```

振动幅值单位即现场读数单位（如 mm/s 或 μm），相位单位为度（°，非负）；
返回 `readings / influence_coefficient / free_enabled_slots / ideal_correction /
candidates / best`，其中 `candidates` 已按预测残余幅值排序。

## 称重误差校核的计算方法

实际质量 m<sub>k</sub>′ = m<sub>k</sub> + δ<sub>k</sub>（−e<sub>k</sub> ≤ δ<sub>k</sub> ≤ e<sub>k</sub>）时：

```
U₁ = R·Σ (mₖ + δₖ)·e^(iθₖ) = U₁_nom + R·Σ δₖ·e^(iθₖ)
```

各管误差彼此独立，U₁ 的可达集合是以 U₁_nom 为中心、以 {R·e<sub>k</sub>·e^{iθₖ}}
为生成元的**二维 zonotope（中心对称凸多边形）**。凸多边形上 |z| 的最大值必在顶点处
取得，因此后端把生成元按方向角排序后沿多边形边界逐顶点求模（**O(n log n)，顶点数 ≤ 2n**），
**不枚举 2ⁿ 个误差组合**，同时记录取得最大值的顶点所对应的一组 δ<sub>k</sub>，即一组
实际质量（`app/weighing.py`，纯标准库）。

注意误差是**向量叠加**：最不利 |U₁| **不等于** |U₁_nom| + R·Σ e<sub>k</sub>。后者把各管
误差绝对值标量直和，只有当最不利方向上所有误差贡献恰好同向时才精确；几何上槽位方向
分散时它会严格高估，界面中会同时展示两个值作为对照。

校核接口的请求示例：

```bash
curl -X POST http://localhost:8000/api/plan/1/weighing-check \
  -H 'Content-Type: application/json' \
  -d '{"tube_errors":[{"tube_id":1,"mass_error_bound_g":0.5},
                       {"tube_id":2,"mass_error_bound_g":0.3}],
       "u1_limit_g_mm":1000}'
```

未出现在 `tube_errors` 中的试管按误差上界 0 处理；`u1_limit_g_mm` 可省略（只计算不判定）。

## 批次换装顺序的计算方法（Held-Karp 精确求序）

设方案 p 的已放置试管数为 occ(p)，方案 a、b 之间“同槽同管”的槽位数为 keep(a, b)。
从方案 a 换装到方案 b：**先卸下**所有不在 b 原槽位的试管，**再装入** b 所需的试管，
每卸下或装入一支试管各计 1 次操作（同槽同管的试管保留不动，不计操作）：

```
trans(a, b) = occ(a) + occ(b) − 2·keep(a, b)     (从空转子到 b: occ(b))
```

一批的成本只取决于相邻两条方案，与更早的批次无关，因此执行次序是 k 条方案上的最短
哈密顿路径。k ≤ 10，服务端用 **Held-Karp 子集动态规划精确求解**（`app/batch.py`，
纯标准库）：`best(mask, prev)` 表示处于 prev 状态（或空转子）时再执行 mask 中全部
方案的最小后续操作数，状态数 2ᵏ·(k+1)（k=10 时约 1.1 万），同一递归还统计达到最小
总操作数的次序条数；同成本时按**方案 ID 序列升序**（字典序）裁决——从首个批次起逐位
选取仍能达到最小值的 ID 最小方案。

接口示例（服务默认监听 <http://localhost:8000>）：

```bash
curl -X POST http://localhost:8000/api/plans/batch-sequence \
  -H 'Content-Type: application/json' \
  -d '{"plan_ids":[1,2,3]}'
```

返回 `order / total_operations / optimal_order_count / plans / batches / rotor`，
其中 `batches` 逐批给出 `unload / load / kept` 清单及 `operations /
cumulative_operations`（单次与累计操作数）。仅接受半径、槽位角度及启用状态相同的
方案；同编号试管质量不一致返回 400。结果只读，不保存、不覆盖原方案。

## 逐管安全装载的计算方法（子集动态规划）

设方案中 n 支已放置试管（n ≤ 16）的最终槽位 θₖ 与标称质量 mₖ 固定，
vₖ = R·mₖ·e^{iθₖ}（g·mm）。从空转子开始每步装入一支试管，装入子集 S 时的中间
状态不平衡量 U₁(S) = Σ_{k∈S} vₖ，全过程峰值为 max_t |U₁(S_t)|。服务端用子集动态
规划**精确**最小化该峰值（`app/loading.py`，纯标准库，状态数 2ⁿ ≤ 65536）：

```
U[mask]  = Σ_{k∈mask} vₖ                              子集向量和(递推 O(2ⁿ))
dp[mask] = min_{j∈mask} max(dp[mask∖{j}], |U[mask]|)   装完 mask 的最小过程峰值
h[mask]  = min_{j∉mask} max(|U[mask∪{j}]|, h[mask∪{j}]) 自 mask 出发的最小后续峰值
```

最小全过程峰值 A = dp[全集]；达到最小峰值的次序条数在“子集模长不超过 A”的
状态格中数路径得到（一条次序的峰值 ≤ A 当且仅当它经过的每个子集模长都 ≤ A）。
并列最优按**试管编号序列升序**（字典序）裁决：从第一步起逐位尝试剩余试管中编号
最小者 j，若 max（当前前缀峰值， |U[T∪{j}]|, h[T∪{j}]) 仍等于 A 则选定之。

接口示例（服务默认监听 <http://localhost:8000>）：

```bash
curl -X POST http://localhost:8000/api/plan/1/loading-sequence \
  -H 'Content-Type: application/json' \
  -d '{"u1_limit_g_mm":5000}'
```

`u1_limit_g_mm` 可省略（只计算不判定）。返回 `order / peak_u1_g_mm /
final_u1_g_mm / optimal_order_count / steps / exceeded_steps / within_limit`，
其中 `steps` 逐步给出装入管号、槽位、当步 |U₁| 与累计峰值。超过 16 支试管
返回 400 明确拒绝。结果只读，不保存、不覆盖原方案。

## 失效槽位应急迁移的计算方法（按移动管数分层完全枚举）

方案确定后，n 支试管各自的原槽位 θₖ 与标称质量 mₖ 固定。出现若干新失效槽位后，
需在不改动试管质量的前提下把少量非锁定试管迁移到其余有效槽位：

- **锁定试管不得移动**；其原槽若为失效槽则结构上无可行摆放；
- **失效槽位不得占用**（原本禁用槽同样不可用）；
- 最多移动 M 支非锁定试管（**M = 0~3**），一支试管换一个槽计 1 次移动；
  被移动试管允许落到另一支被移动试管空出的原槽（成对交换、链式迁移均可）；
- 迁移后 `U₁ = R·Σ mₖ·e^{iθₖ(final)}` 必须不超过给定限值 L（必填，非负）。

设失效槽上的非锁定试管有 f 支（**必须**迁走），有效空槽（启用、非失效、未被占用）
有 q 个。若恰好移动 k 支（f ≤ k ≤ M），可注入的目标槽池共 q + k 个（q 个空槽加
k 个被移动试管腾出的原槽；其中压在失效槽上的必迁管原槽是失效槽，**不**进入槽池）。
服务端枚举全部移动子集（≤ C(10,k) ≤ 120）与全部合法目标槽注入
（≤ P(q+k,k)，k≤3 时至多 9·8·7=504 种），用回溯剪枝保证目标槽唯一且不等于该管
原槽，k=0..3 的叶子总数至多约 4.4 万，瞬时完成（`app/evacuation.py`，纯标准库）。

分层搜索从 k = f 到 k = M 依次枚举，**第一个存在可行摆放（|U₁| ≤ L）的 k 即最少
移动管数**；在该层的可行摆放中取最终 |U₁| 最小者，数值容差（1e-9 相对容差）内并列
时按**管号升序的目标槽位序列**（final_slot(tube_id 最小), final_slot(tube_id 次小), …；
未移动试管的目标槽即原槽）字典序最小者裁决，并统计达到该最优结果的摆放条数。
任何 k 都找不到满足限值的摆放时，返回 `feasible: false` 并明确说明，同时给出移动
上限内 |U₁| 最小的对照摆放（`best_effort`，仅供参考）；锁定管压在失效槽、必迁管数
超过上限或无有效目标槽等结构性不可行则不产生目标摆放。

接口示例（服务默认监听 <http://localhost:8000>）：

```bash
curl -X POST http://localhost:8000/api/plan/1/slot-evacuation \
  -H 'Content-Type: application/json' \
  -d '{"failed_slots":[3,9],"u1_limit_g_mm":1000,"max_moves":3}'
```

返回 `feasible / moves_required / optimal_arrangement_count / final_u1 /
original_u1 / tubes（逐管原槽/目标槽）/ moves / failed_slots / best_effort /
reason`；不可行时 `feasible=false` 并在 `reason` 中明确说明。仅接受至多 10 支管、
16 个启用槽位、移动上限 0~3 的方案；失效槽位含不存在槽、原本禁用槽或重复槽位返回 400。
结果只读，不保存、不覆盖原方案。

## 现场装管复核的计算方法（子集 DP 最小总绝对质量差匹配）

方案确定后，n 支试管各有标称质量 mₖ 与方案槽位 sₖ。现场装管后按启用槽录入实测
读数 rⱼ（实际有管槽位 + 天平实测质量，精度 0.01 g，至多 12 份）与统一允许偏差 e。
读数 j 可能对应试管 k 当且仅当 `|mₖ − rⱼ| ≤ e`；复核即在该二分图上求试管与读数的
**一对一匹配**（完美匹配），并以**总绝对质量差最小**为准。读数最多 12 份，故完整
匹配时 n ≤ 12，服务端用子集动态规划**精确**求解（`app/recheck.py`，纯标准库）：

```
f(i, S) = min_{j∈S} f(i-1, S\{j}) + |mᵢ - rⱼ|      前 i 支试管匹配读数集 S
g(i, S) = min_{j∈S} |mᵢ - rⱼ| + g(i+1, S\{j})      第 i 支起匹配读数集 S
C*      = f(n, 全集)                                  最小总绝对质量差
```

边 (k, j) 出现在**某个最优匹配**中，当且仅当存在不含 j 的读数集 S 使
`f(k, S) + |mₖ − rⱼ| + g(k+1, 全集\S\{j\}) = C*`（1e-9 相对容差）。据此对每个实测槽
汇总**所有最优匹配**可能对应的试管——不逐一枚举最优匹配（退化情形可达 n! 条；条数
用同一 DP 以任意精度整数计数）：

- **候选唯一**：该槽读数在全部最优匹配中都对应同一支试管——按原方案槽位判定
  **正确**（读数槽即该管方案槽）或**错槽**（读数槽不是该管方案槽）；
- **候选多解**：标为**身份不确定**——不能任取一个最优匹配断言错放。

对称地，结果也汇总每支方案试管在全部最优匹配中可能落入的实测槽位，供交叉核对。
**读数数量与方案管数不等**时不做匹配并说明原因；**不存在完整匹配**时给出最多可
匹配对数，以及在偏差内无任何兼容读数的试管、无任何兼容试管的读数清单。

接口示例（服务默认监听 <http://localhost:8000>）：

```bash
curl -X POST http://localhost:8000/api/plan/1/tube-recheck \
  -H 'Content-Type: application/json' \
  -d '{"readings":[{"slot":0,"mass":50.01},{"slot":3,"mass":51.0},
                    {"slot":6,"mass":52.0},{"slot":9,"mass":53.0}],
       "tolerance_g":0.05}'
```

返回 `complete / total_abs_deviation_g / optimal_matching_count / readings
（逐实测槽候选试管与判定）/ tubes（逐方案试管可能槽位）/ summary / reason`；
`complete=false` 时 `reason` 明确说明（数量不等或不存在完整匹配，附最多可匹配
对数与无兼容对象清单）。实测质量须为 0.01 g 整数倍的正数，读数 1~12 份、槽位不得
重复且必须为方案中的启用槽，统一允许偏差非负，违反返回 400。结果只读，不保存、
不覆盖原方案。

## 复称规划的计算方法（按复称管数分层完全枚举）

方案确定后，每支试管 k 固定在槽位 θ_k，标称质量 m_k，并有当前称重质量误差上界
e_k（0 ≤ e_k ≤ m_k，未录入按 0）。复称（重新称量）试管 k 只把该管误差上界降为
**两者较小值** `min(e_k, b)`（b 为复称后的统一误差上界），标称质量与落槽不变；
复称组合 S 确定后，最不利一阶不平衡量仍由现有的二维 zonotope 顶点枚举**精确**
求得（`app/weighing.py`，见“称重误差校核的计算方法”）。

只有当前上界 e_k > b 的试管复称后上界才会真正下降（**有效候选**，共 c 支）；复称
其余试管不改变任何误差上界，不可能改善结果。服务端对有效候选按复称管数分层完全
枚举（`app/reweigh.py`，纯标准库，至多 24 支已放置试管）：

```
子集数 = Σ_{k=0..M} C(c, k)        (M ≤ 3, n ≤ 24 时至多 2325 个组合)
每个组合把被复称管上界改为 min(e_k, b) 后调用一次 worst_case_u1(O(n log n))
```

目标排序（确定性）：① 能达标（复称后最不利 |U₁| ≤ 限值 L）的**最少复称管数**
k\*——从 k=0 起逐层枚举，首个存在达标组合的 k 即 k\*；② 在大小为 k\* 的达标
组合中取复称后最不利 |U₁| **最低**者；③ 数值容差（1e-9 相对容差）内并列时按
**管号序列升序**（字典序）裁决，并统计达到该最优结果的组合数。若 0..M 内均无法
达标，返回次数内最不利 |U₁| 最低的组合（并列时先取复称管数少者，再按管号序列
升序）及超限量，明确判定**不达标**，不误报达标。

接口示例（服务默认监听 <http://localhost:8000>）：

```bash
curl -X POST http://localhost:8000/api/plan/1/reweigh-plan \
  -H 'Content-Type: application/json' \
  -d '{"tube_errors":[{"tube_id":1,"mass_error_bound_g":0.5},
                       {"tube_id":2,"mass_error_bound_g":0.3}],
       "reweighed_error_bound_g":0.05,
       "u1_limit_g_mm":1000,
       "max_reweigh_count":3}'
```

返回 `feasible / reweigh_count / reweighed_tube_ids /
optimal_combination_count / baseline（复称前标称与最不利）/ final（复称后标称、
最不利与一组实际质量）/ tubes（逐管复称前后误差上界）/ within_limit /
excess_g_mm / reason`；未出现在 `tube_errors` 中的试管按当前上界 0 处理。
限值或统一上界为负/非有限、复称次数越界（0~3 之外）、误差上界超过标称质量、
试管不在摆放明细中、已放置试管超过 24 支等均返回 400。结果只读，不保存、
不覆盖原方案。

## 备品试管替换的计算方法（备品不重复使用的一对一精确枚举）

方案确定后，每支试管 k 固定在槽位 θ_k、标称质量 m_k、转子半径 R。选定 r 支
待换管（1 ≤ r ≤ 4，均为方案中已放置试管）并录入 s 支备品（1 ≤ s ≤ 12，编号
互不相同、质量为正、且不与原方案管号冲突）。替换时**保留原槽位**：每支待换管
从其原槽取下，一支备品装入同一槽位；**备品不得重复使用**，即待换管与备品之间
构成一对一映射（单射），其余未换管及其槽位完全不动。映射确定后的最终一阶不平衡量

```
U₁ = U₁(base) + R · Σ_j (m′_j − m_j) · e^{iθ_j}      (g·mm)
```

其中 j 遍历待换管（θ_j 为该管原槽角度，m′_j 为换上的备品质量）。服务端把待换管
按管号升序固定为位置 1..r，对全部排列做**精确完全枚举**（`app/spare_replacement.py`，
纯标准库）：

```
映射数 = P(s, r) = s!/(s−r)!     r ≤ 4、s ≤ 12 时至多 12·11·10·9 = 11880 个
```

目标排序（确定性）：① 在**达标**（最终 |U₁| ≤ 限值 L）映射中取**总质量差
Σ|m′−m| 最小**者；② 数值容差（1e-9 相对容差）内并列时取最终**残余 |U₁| 最小**
者；③ 仍并列时取**待换管号（升序）顺序对应的备品编号序列**字典序最小者，并统计
达到该最优结果的映射条数。若没有任何达标映射，返回**残余 |U₁| 最低**的映射
（容差内并列时按备品编号序列裁决）、超限量 max(0, |U₁|−L) 与**不达标**结论，
不误报达标。最终 |U₁| 与总质量均由裁决序列独立复算，不依赖搜索时的浮点累加。

接口示例（服务默认监听 <http://localhost:8000>）：

```bash
curl -X POST http://localhost:8000/api/plan/1/spare-replacement \
  -H 'Content-Type: application/json' \
  -d '{"replaced_tube_ids":[1,2],
       "spares":[{"tube_id":10,"mass_g":50.2},{"tube_id":11,"mass_g":49.8}],
       "u1_limit_g_mm":1000}'
```

返回 `feasible / replaced_tube_ids / spares / evaluated_mappings /
feasible_mapping_count / baseline（替换前 |U₁|、总质量、离心力与限值判定）/
mappings（逐管：原管/原槽角度、备品编号与质量、质量差、替换前后质径积贡献）/
unchanged_tubes（保留不动的未换管）/ tubes（按槽位的最终摆放）/
total_mass_diff_g / optimal_mapping_count / final（替换后 |U₁|、总质量、离心力）/
within_limit / excess_g_mm / reason`。待换管数量越界（1~4 之外）或重复、待换管
不在摆放明细中、备品为空或超过 12 支、备品编号重复或与原方案冲突、备品质量非正、
备品数量少于待换管、限值为负/非有限等均返回 400。结果只读，不保存、不覆盖原方案。

## 物理模型

单面转子、所有试管位于同一半径 R：

- 一阶不平衡量（质径积）：`U₁ = R·Σ mₖ·e^{iθₖ}`，单位 g·mm
- 二阶不平衡量：`U₂ = R·Σ mₖ·e^{i·2θₖ}`，单位 g·mm
- 离心合力：`F = ω²·|U₁|·1e-6`（N，g·mm → kg·m）
- 合力矩：`M = F·R/1000`（N·m）
- 等效偏心距：`e = |U₁| / Σm`，评级 A ≤1μm，B ≤5μm，C ≤20μm，D >20μm
